# Luis Gabuardi — Portafolio

Sitio personal con narrativa por scroll: un campo de partículas se transforma en cada proyecto mientras el texto se revela sincronizado, como una película.

## Escenas

| Escena | Figura |
|---|---|
| Inicio | Esfera |
| Sobre mí | Superficie de onda |
| [Algorithm City](https://github.com/LUISGABUAS/Algorithm-City) | Ciudad |
| [EXORA Finances](https://apps.apple.com/mx/app/exora-finances/id6781416549) | Teléfono con gráfica |
| [Pacas Yadira](https://github.com/LUISGABUAS/PROYECTO-V2) | Rack de almacén |
| [Cubicación & Rutas](https://github.com/LUISGABUAS/Algoritmos-Cubicacion---Rutas-Transporte-Consolidado) | Tráiler con carga |
| [Learn Algorithms](https://github.com/LUISGABUAS/Learn_Algorithms) | Árbol binario |
| Más trabajo y contacto | Anillo y esfera |

## Stack

- HTML, CSS y JavaScript en un solo archivo, sin build
- Partículas dibujadas en Canvas 2D
- [GSAP](https://gsap.com) + ScrollTrigger para la coreografía del scroll
- [Lenis](https://lenis.darkroom.engineering) para el scroll suave
- Tipografía Inter y Geist Mono
- Modo claro y oscuro automático; respeta `prefers-reduced-motion`

## Correr en local

Abre `index.html` en el navegador, o sirve la carpeta:

```bash
npx serve .
```
